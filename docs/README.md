# NetBite documentation

- `architecture/` documents system boundaries, data design, remote curriculum, and instructor workshops.
- `product/` documents curriculum, engagement, usability, robustness, and implementation direction.
- `standards/` contains teaching, assessment, simulation, content, visual, and portal interface standards.
- `runbooks/` contains setup, demonstrations, handover, and developer operating guidance.
- `references/` records primary technical sources used by the curriculum and simulators.

Coursework-specific instructions and reports belong in `schoolwork/`, not in production documentation.
