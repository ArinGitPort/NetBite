# NetBite HCI Review Standard

## Purpose

NetBite should look like a compact training console without making every control look equally important. The interface prioritizes recognition, clear grouping, progressive disclosure, immediate feedback, and prevention of avoidable errors.

## Interaction rules

1. Show one primary action for the learner's current task.
2. Place supporting actions near the content they affect.
3. Pair familiar icons with labels; icons do not replace text.
4. Keep advanced and destructive controls behind labeled disclosures when they are not part of the current task.
5. Communicate state with words or symbols as well as color.
6. Preserve a neutral Cancel action and use a distinct destructive Confirm action.
7. Prevent duplicate submissions while navigation, authentication, synchronization, or checkout is pending.
8. Keep all controls at least 44 points and allow labels to wrap at increased font scales.
9. Prefer recognition over recall: offer contextual guidance, saved references, and deterministic explanations near the task that needs them.
10. Restore focus to the changed task or feedback region after modal closure, staged navigation, and review advancement.

## Task-based acceptance review

### 1. Start the next lesson

- The first actionable menu panel is Start Learning or Continue Learning.
- It names the current chapter and next activity, shows real progress, and contains the smaller Browse All Chapters action.
- Account and Settings do not visually compete with it.

### 2. Browse another chapter

- Browse All Chapters is inside the learning group.
- The learning path marks the current chapter, completed chapters, and locked chapters with different labels, icons, and treatments.

### 3. Understand the locked Sandbox

- Network Sandbox has a network icon and orange signal treatment.
- Locked access shows a lock, `PRO / LOCKED`, and `VIEW PRO ACCESS`; it does not resemble an enabled workspace shortcut.

### 4. Find Settings

- Settings appears in the Account & App utility group.
- The Settings screen groups Cloud Progress, Preferences, Presentation, and Destructive Local Data by purpose.

### 5. Retry cloud synchronization

- Cloud status is visible as Local, Syncing, Synced, or Action Needed.
- Action Needed displays a Retry Cloud Sync command and confirms that the local copy remains safe.

### 6. Reset data safely

- Reset and erase actions are hidden under Destructive Local Data until deliberately expanded.
- Each action opens a specific confirmation dialog.
- Cancel is neutral; the destructive confirmation names exactly what will be removed.

## Review checklist

- Can a first-time learner identify the primary action without reading every panel?
- Can navigation, task commands, utilities, selections, and destructive controls be distinguished by placement, icon, label, and shape?
- Does the current task remain obvious after rotation, web resizing, or larger system text?
- Are optional tools discoverable without permanently occupying primary space?
- Does every failure explain recovery without discarding local work?
- Can the same task be completed with touch, keyboard, and screen-reader navigation?
- Can a learner explain why a simulated result occurred without relying on animation or color?
- Can a learner recover a weak topic without confusing completion with mastery?

Run this review at 360, 390, 430, 500, 768, and 1024-point widths, with increased font scaling and reduced motion.
