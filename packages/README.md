# NetBite shared packages

Only platform-independent code belongs here. React DOM components stay in `apps/portal`, and React Native components stay in `apps/mobile`.

- `@netbite/networking` contains pure networking calculations shared by authoring and learning experiences.
- `@netbite/workshops` contains workshop contracts, validation-safe data helpers, and read-only command generation.
- `@netbite/brand` contains brand artwork used by both applications. Native icons and splash assets remain in the mobile application.
