Activity: Timeline & Development Plan (Week 3)
Due August 3, 2026 12:00 PM
Instructions
Objective
This activity aims to help each project team develop a realistic implementation plan for their proposed system. Students will organize their project schedule, identify key milestones, anticipate possible risks, and present their Week 2 progress.



Deliverables
Each must submit the following:

1. Project Timeline / Gantt Chart
Create a detailed project timeline showing the major activities from project initiation until project completion.

The Gantt Chart should include:

Project phases
Tasks and subtasks
Start and end dates
Duration of each activity
You may use:

Microsoft Excel
Microsoft Project
Google Sheets
Canva
Lucidchart
Any Gantt Chart software
2. Milestones and Deliverables
Identify the important milestones of your project.


Example:

Milestone	Expected Output	Target Date
Project Proposal Approved	Approved Proposal	Week 2
System Design Completed	Design Documents	Week 4
Prototype Finished	Functional Prototype	Week 6
System Testing	Test Report	Week 8
Final System Completed	Completed System	Week 10
Final Presentation	Presentation & Documentation	Week 11

3. Risk Assessment and Contingency Plan
Identify possible project risks and explain how your team will respond if they occur.

Example:

Risk	Impact	Contingency Plan
Team member unavailable	Medium	Reassign tasks to other members
Delay in coding	High	Adjust schedule and prioritize core features
Internet connectivity issues	Medium	Prepare offline copies and backup internet access
Hardware failure	High	Use cloud storage and backup devices
Scope changes	High	Obtain adviser approval before implementation

Include at least 5 identified risks.

Submission Requirements
Submit the following files through Microsoft Teams:

PDF or Image of the Gantt Chart
Milestones and Deliverables Document (PDF or Word)
Risk Assessment & Contingency Plan (PDF or Word)
Week 2 Presentation (PPTX or PDF)
